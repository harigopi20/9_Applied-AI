03Hybrid approach

Who does what

Developer

Vibe coding · Lovable

Screens, backend and database. The Planner agent inside the app. Safety rules written as code.

Output: working app + code in GitHub
Tester

AI agents · Claude

Create requirements and test cases. Test runs, red-team verifies functional and safety requirements, and provide go/no-go report.

Output: tests + reports in GitHub
Decision maker

Humans · Team

Writes the prompts, reviews every result, approves each phase, runs user tests.

Output: approval at each phase gate
Why hybrid: a fast working demo, with agents used where they add the most value, which is quality and safety
